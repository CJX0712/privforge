# 模型卡（Model Card）

## 模型细节
- **架构**：两层隐藏层 MLP（ReLU），默认 32→16→2，容量小、CPU 友好。
- **损失**：交叉熵；输出 softmax 概率。
- **训练后端**：
  - `NonPrivate`：标准 mini-batch SGD（效用上界，无隐私）。
  - `FixedClip-DP-SGD`：固定裁剪界 DP-SGD（SOTA 算法原版）。
  - `DPFuse`：自适应裁剪 DP-SGD（旗舰）。

## 预期用途
- 在隐私约束下训练分类模型；量化「给定 (ε,δ) 的效用损失」。
- 教学/研究：演示 DP-SGD、RDP 会计、自适应裁剪的可验证实现。

## 训练数据
- 默认：`data/synthetic.py` 确定性二分类 DGP（可复现，无下载）。
- 可替换为任意 `(X, y)` 表格分类数据（需满足差分隐私的「每次训练只接触一份数据集」假设）。

## 隐私保障
- 提供 `(ε, δ)` 由 RDP 矩会计严格给出（高斯机制，敏感度上界 = 裁剪界 C）。
- 隐私开销只取决于 `(σ, steps)`，与裁剪界无关。
- 属集中式训练隐私（central DP），非本地 DP / 本地化噪声。

## 局限性
- 默认合成数据；真实数据需自行评估效用与隐私假设。
- CPU-only 小模型，非大模型训练框架（对标的是算法正确性与可复现性，而非吞吐）。
- `σ` 过大会使效用坍缩至随机水平（见失败案例）。
- 未覆盖：本地 DP、联邦 DP、私密聚合（SECAGG）等高级协议。
